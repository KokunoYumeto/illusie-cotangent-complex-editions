# Volume II cumulative checkpoint through printed page 174

This directory records the accepted boundary of a partial Volume II working
edition. It covers the seven-leaf front matter and printed pages 1–174 in
diplomatic French, corrected French, and source-aligned English.

The PDFs and exact 543-file source snapshot are attached to the public GitHub
release and to the matching version of Zenodo concept DOI
`10.5281/zenodo.21792257`. The files here provide the bounded source inventory,
deterministic validation, page-174 receipt, and publication cursor.

Printed page 175 and every later page are outside this checkpoint. Page 175
requires a one-line English correction before it can enter a later cumulative
release; the defect is tracked in
[issue 3](https://github.com/KokunoYumeto/illusie-cotangent-complex-editions/issues/3).

This checkpoint does not claim Volume II completion. Volume I remains complete
and is preserved byte-for-byte in the cumulative release.
